## 1. 実装の状況

| 対象 | 現状 |
| --- | --- |
| Neon SQL | `011`投稿・投稿メディア、`012`不要INDEX整理、`013`トランザクション関数、`014`メディア削除保護、`015`選択曲には音声必須 |
| Backend | 投稿POST、GET一覧・詳細、PATCH、DELETE、本人／公開プロフィール別一覧、PostMedia署名URL発行 |
| Frontend | 投稿作成、本文と音声／画像アイコン、録音／ファイル／保存済み音声と曲選択、画像アップロード／再利用、入力エラー表示 |
| 一覧・詳細 | Community、MyPage、UserProfile、Searchの実API接続、投稿カード全体で詳細へ遷移、音声プレビュー、画像 |
| 投稿者の操作 | マイページ経由の本人投稿のみ詳細の削除メニュー表示。削除は確認ダイアログで実行、Media/R2は保持 |
| 権限 | Profile単位 public または本人に限定。followers/privateはフォロー未実装のため本人のみ |
| 保存制限 | 本文・音声・画像いずれか1つ以上。曲は任意だが曲選択時は音声必須。画像5枚／音声1件 |
| 残る非対応 | フォロー、いいね、コメント、タイムスタンプコメント、独自登録曲の全ユーザー横断検索、募集の実データ化は本STEP対象外 |

**注意**：Backendの`PATCH /posts/:id`と編集画面の実装コードは残しているが、投稿詳細の編集メニューは現在非表示。投稿元`?from=my-page`の表示条件はセキュリティ境界ではなく、APIはJWTと投稿者IDで認可する。
